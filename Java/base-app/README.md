# 初识 Java

Java 1995年推出，应用领域包括大数据开发、游戏开发、安卓移动端开发、企业级服务器开发

JDK LTS版本：8、11、17、21、25（最新）

## 语法

### 字面量

整数、小数、字符串（双引号）、字符（单引号，且内容只有1个）、布尔、空（null）

### 变量

数据类型 变量名 = 数据值 `int a = 10;` `double b = 10`

数据以二级制的形式存储，字节是计算机中的最小存储单元，1字节=8bit位，java中的int占4个字节/32个bit位

#### 基本数据类型

4个整数类型：byte（1字节）、short（2字节）、int（4字节）、long（8字节，必须以L结尾）

2个小数类型：float（4字节，必须以F结尾）、double（8字节）

字符类型：char（2字节）

布尔类型：boolean（1字节）

### 运算符

算数运算符：+ - * / %，注意小数运算是有可能不精确的

```java
// 一个经典的简单算法题，获取一串数字的个十百
int number = 123;

int ge = number % 10;
int shi = number / 10 % 10;
int bai = number / 100 % 10;
```

隐式转换：
1. 不同类型的数据进行计算的时候会自动进行隐式转换
2. bute、short类型会提升位int类型
3. 取值范围小的会提升为取值范围大的再运算，由小到大：byte-short-int-long-float-double

强制转换：
1. 不会自动转换，需要手写代码转换
2. 目标数据类型 变量名 =（目标数据类型）被强转的数据

**字符类型**在运算中会根据ASCII码表转成对应的数字

**字符串类型**只能+操作，并且和任何数据都是拼接

自增自减运算符：++、--
关系运算符：==、!=、>、>=、<、<=
逻辑运算符：&、|、!
短路运算符：&&、||
三元运算符：?:

> 这些运算符在js中几乎完全相同，就当巩固了
