# 14.元组

数组合并了**相同**类型的对象，元组合并了**不同**类型的对象。
元组起源于函数编程语言（F#），并被频繁使用。
​

## 14.1 元组的使用
定义一对值分别为`string`、`number`类型的元组。
```typescript
let tom: [string, number] = ['tom', 25]
```


赋值或访问一个已知索引的元素时，会得到正确的类型：
```typescript
let tom: [string, number];
tom[0] = 'Tom';
tom[1] = 25;

tom[0].slice(1);
tom[1].toFixed(2);
```
也可以只赋值其中一项：
```typescript
let tom: [string, number];
tom[0] = 'Tom';
```
但是当直接对元组类型的变量进行初始化或赋值的时候，需要提供所有元组类型中指定的项：
```typescript
let tom: [string, number];
tom = ['Tom', 25];
// 成功

let tom: [string, number];
tom = ['Tom'];
// 报错，缺少索引 1 的值
```


## 14.2 越界的元素
当添加越界元素时，它的类型被限制为元组的“每个类型组成的联合类型”
<!-- 修订注：这说明 `push` 这类数组方法可能仍能改变元组的运行时长度，并不代表元组在运行时有固定长度保护。现代 TS 中元组的静态长度信息更强，但直接调用数组变异方法仍要谨慎。 -->
```typescript
let tom: [string, number];
tom = ['Tom', 25];
tom.push('male'); // 成功
tom.push(true); // 报错，true不属于 string｜number 联合类型
```
