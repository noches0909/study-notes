## 4.1 类型推论介绍
如果一个变量声明并**赋值**的时候没有指定类型，那么TypeScript会按照类型推论推断出一个类型。
```typescript
let myFavoriteNumber = 'seven';
let myFavoriteNumber: string = 'seven';
// 二者等价

myFavoriteNumber = 7;
// 随后赋值会报错
```


> 过时提醒：如果声明时没有赋值，变量会先被推断为隐式 `any`，随后可能根据控制流被收窄；在开启 `noImplicitAny`/`strict` 的现代项目中，应尽量显式标注类型或尽快初始化。
**如果声明的时候没有赋值，那么会先被判定为 `any` 类型。**
```typescript
let myFavoriteNumber;
myFavoriteNumber = 'seven';
myFavoriteNumber = 7;
```
